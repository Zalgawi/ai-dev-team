# Trail 100 Tracker

## Overview

A personal web application for tracking progress through the
Live for the Outdoors Trail 100 challenge.

The challenge consists of 100 UK peaks.

Refer to the list of 100 in trail-100-list.txt (https://www.livefortheoutdoors.com/trail-100/)

## Primary goal

Allow a user to:

- browse all 100 peaks
- see which peaks they have completed
- mark peaks as completed
- track overall progress
- view progress by region
- view individual peak information

## Initial scope

The first version should focus on:

- Trail 100 peak dataset
- peak explorer
- completion tracking
- progress dashboard

Do not implement accounts, social features,
payments or complex route planning in V1.

## Acceptance criteria

The application must:

- contain all 100 Trail 100 peaks
- display peak name
- display elevation
- display region
- display grid reference
- allow a peak to be marked complete
- allow a completed peak to be unmarked
- display overall completion percentage
- display completed / remaining counts
- work on mobile and desktop
- have accessible interactive controls
- have automated tests for core functionality
